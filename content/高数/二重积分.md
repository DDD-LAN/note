## 第一节 二重积分的高效计算与对称性应用

### 知识精要（对应 PDF 第 1、2、3 页）

1. **二重积分对称性原则（计算第一准则）**：
   * **普通对称性（奇零偶倍）**：
     * 若区域 $D$ 关于 $y$ 轴对称：被积函数 $f(x,y)$ 关于 $x$ 为奇函数则积分为 $0$；为偶函数则等于半个区域上积分的 $2$ 倍。
     * 若区域 $D$ 关于 $x$ 轴对称：被积函数 $f(x,y)$ 关于 $y$ 为奇函数则积分为 $0$；为偶函数则等于半个区域上积分的 $2$ 倍。
   * **轮换对称性**：
     * 若区域 $D$ 关于直线 $y = x$ 对称，将式中所有 $x, y$ 互换，积分值不变：
       $$\iint_D f(x,y)\,\mathrm{d}\sigma = \iint_D f(y,x)\,\mathrm{d}\sigma = \frac{1}{2}\iint_D \big[f(x,y) + f(y,x)\big]\,\mathrm{d}\sigma$$
2. **形心坐标公式与对称平移**：
   * 平面薄板形心横纵坐标：$\bar{x} = \frac{\iint_D x\,\mathrm{d}\sigma}{S_D}, \; \bar{y} = \frac{\iint_D y\,\mathrm{d}\sigma}{S_D} \implies \iint_D x\,\mathrm{d}\sigma = \bar{x}\cdot S_D, \; \iint_D y\,\mathrm{d}\sigma = \bar{y}\cdot S_D$。
   * 若区域关于 $x = x_0$ 对称，直接拆项 $x = (x - x_0) + x_0$，奇次项为 $0$，常数项乘面积。
3. **坐标系决策准则**：
   * **直角坐标**：边界为多边形、直线或简单抛物线，内层易积出。
   * **极坐标**：
     * 被积函数含 $x^2 + y^2$ 或 $f\left(\frac{y}{x}\right)$（**“选择困难，优先考虑被积函数”**）。
     * 区域边界为圆、圆环、扇形、心形线、双纽线。
   * **平移极坐标**：当圆心在 $(x_0, y_0)$、半径为 $R$ 时，令 $\begin{cases} x - x_0 = \rho\cos\theta \\ y - y_0 = \rho\sin\theta \end{cases}$，$\mathrm{d}\sigma = \rho\,\mathrm{d}\rho\,\mathrm{d}\theta$，此时 $\rho \in [0, R], \theta \in [0, 2\pi]$，免去复杂三角函数上下限。
4. **常考四大曲线参数方程与极坐标**：
   * 摆线：$\begin{cases} x = a(t - \sin t) \\ y = a(1 - \cos t) \end{cases} \quad (0 \le t \le 2\pi)$
   * 双纽线：$(x^2 + y^2)^2 = a^2(x^2 - y^2) \iff r^2 = a^2\cos 2\theta$
   * 星形线：$x^{2/3} + y^{2/3} = a^{2/3} \iff \begin{cases} x = a\cos^3 t \\ y = a\sin^3 t \end{cases}$
   * 心形线：$r = a(1 + \cos\theta)$

### 【必做例题 01】偏心圆域的多法速算（PDF 第 4 页例题）

**【题目】** 计算二重积分：
$$\iint_D (x + y)\,\mathrm{d}\sigma$$
其中积分区域 $D$ 是由不等式 $x^2 + y^2 \le x + y$ 所确定的平面闭区域。

> [!warning] 原笔记核心批注与避坑指南
> * **切忌死算**：此题边界配方后为 $\left(x - \frac{1}{2}\right)^2 + \left(y - \frac{1}{2}\right)^2 \le \frac{1}{2}$，圆心偏离原点。如果强行用标准极坐标，极角切线和极径上下限包含复杂的正余弦组合，计算极易出错崩溃。
> * **提速三板斧**：
>   1. **平移极坐标**：把极点平移至圆心 $\left(\frac{1}{2}, \frac{1}{2}\right)$，极径上限化为常数 $\frac{\sqrt{2}}{2}$，三角项一次方在对称区间积分直接为 $0$。
>   2. **奇偶性平移**：拆项为 $\left(x - \frac{1}{2}\right) + \left(y - \frac{1}{2}\right) + 1$，利用图形对称性直接消除前两项。
>   3. **形心公式**：对称图形形心一目了然，$\bar{x} = \frac{1}{2}, \bar{y} = \frac{1}{2}$，结果直接等于 $(\bar{x} + \bar{y})\cdot S_D$。

> [!tip]- 参考解答与解析
> <small>
>
> **方法一：形心公式法（考场首选秒杀）**
> 1. 配方：$\left(x - \frac{1}{2}\right)^2 + \left(y - \frac{1}{2}\right)^2 \le \left(\frac{\sqrt{2}}{2}\right)^2$，圆心为 $\left(\frac{1}{2}, \frac{1}{2}\right)$，半径 $R = \frac{\sqrt{2}}{2}$。
> 2. 由几何对称性，形心坐标为 $\bar{x} = \frac{1}{2}, \; \bar{y} = \frac{1}{2}$，圆盘面积 $S_D = \pi R^2 = \pi \left(\frac{\sqrt{2}}{2}\right)^2 = \frac{\pi}{2}$。
> 3. 由形心积分公式得：
>    $$\iint_D (x + y)\,\mathrm{d}\sigma = \bar{x}\cdot S_D + \bar{y}\cdot S_D = \frac{1}{2}\cdot\frac{\pi}{2} + \frac{1}{2}\cdot\frac{\pi}{2} = \frac{\pi}{2}$$
>
> **方法二：奇偶性平移法**
> 1. 将被积函数关于对称中心拆分：$x + y = \left(x - \frac{1}{2}\right) + \left(y - \frac{1}{2}\right) + 1$。
> 2. 由于区域 $D$ 分别关于直线 $x = \frac{1}{2}$ 和 $y = \frac{1}{2}$ 对称，奇次差项积分为零：
>    $$\iint_D \left(x - \frac{1}{2}\right)\mathrm{d}\sigma = 0, \quad \iint_D \left(y - \frac{1}{2}\right)\mathrm{d}\sigma = 0$$
> 3. 从而原式简化为面积积分：
>    $$\iint_D (x + y)\,\mathrm{d}\sigma = \iint_D 1\,\mathrm{d}\sigma = S_D = \frac{\pi}{2}$$
>
> **方法三：平移极坐标法**
> 1. 令 $x - \frac{1}{2} = \rho\cos\theta, \; y - \frac{1}{2} = \rho\sin\theta$，面积微元 $\mathrm{d}\sigma = \rho\,\mathrm{d}\rho\,\mathrm{d}\theta$，其中 $\theta \in [0, 2\pi], \; \rho \in \left[0, \frac{\sqrt{2}}{2}\right]$。
> 2. 代入积分表达式：
>    $$\iint_D \big[\rho(\cos\theta + \sin\theta) + 1\big]\rho\,\mathrm{d}\rho\,\mathrm{d}\theta = \int_0^{2\pi}\mathrm{d}\theta \int_0^{\frac{\sqrt{2}}{2}} \rho\,\mathrm{d}\rho = 2\pi \cdot \left[\frac{1}{2}\rho^2\right]_0^{\frac{\sqrt{2}}{2}} = \frac{\pi}{2}$$
> </small>

### 【必做例题 02】作辅助线切割构造对称性（PDF 第 3 页例题 · 李林880精选）

**【题目】** 计算二重积分：
$$J = \iint_D x\big(e^{y^2+\cos y}\sin y - 1\big)\,\mathrm{d}x\mathrm{d}y$$
其中积分区域 $D$ 由曲线 $x = \sin y$、直线 $x = -1$ 以及直线 $y = -\frac{\pi}{2}, y = \frac{\pi}{2}$ 所围成。

> [!warning] 原笔记核心批注与避坑指南
> * **笔记原话警示**：“原积分域无对称性，作一条切割辅助线使两个积分域都具有对称性！”
> * **命题陷阱**：被积函数中的 $x\sin y \cdot e^{y^2+\cos y}$ 形式极其复杂，若不通过对称性直接化零，后续积分步骤根本无法推进。
> * **破局关键**：观察边界曲线 $x = \sin y$（奇函数），立即作辅助曲线 $x = -\sin y$（即 $y = -\arcsin x$），将不对称的区域划分为“关于 $y$ 轴对称的中心区域 $D_1$”和“关于 $x$ 轴对称的边角区域 $D_2$”，使复杂项在两块区域上均因为奇偶性积分为零。

> [!tip]- 参考解答与解析
> <small>
>
> **步骤 1：拆分被积表达式**
> $$J = \iint_D x\sin y \cdot e^{y^2+\cos y}\,\mathrm{d}\sigma - \iint_D x\,\mathrm{d}\sigma = J_1 - J_2$$
>
> **步骤 2：作辅助切割线制造对称性**
> 作辅助曲线 $x = -\sin y$，将区域 $D$ 切割为两部分：
> * 区域 $D_1$：由 $-\sin y \le x \le \sin y, \; -\frac{\pi}{2} \le y \le \frac{\pi}{2}$ 围成，该区域关于 $y$ 轴左右对称。
> * 区域 $D_2$：由 $-1 \le x \le -\sin y, \; -\frac{\pi}{2} \le y \le \frac{\pi}{2}$ 围成，该区域关于 $x$ 轴上下对称。
>
> **步骤 3：验证复杂项** $J_1 = 0$
> 记 $g(x,y) = x\sin y \cdot e^{y^2+\cos y}$：
> * 在 $D_1$ 上，$g(-x,y) = -g(x,y)$ 为关于 $x$ 的奇函数，且 $D_1$ 关于 $y$ 轴对称，故 $\iint_{D_1} g(x,y)\,\mathrm{d}\sigma = 0$。
> * 在 $D_2$ 上，$g(x,-y) = -g(x,y)$ 为关于 $y$ 的奇函数，且 $D_2$ 关于 $x$ 轴对称，故 $\iint_{D_2} g(x,y)\,\mathrm{d}\sigma = 0$。
> 从而 $J_1 = \iint_{D_1} g\,\mathrm{d}\sigma + \iint_{D_2} g\,\mathrm{d}\sigma = 0$。
>
> **步骤 4：计算常规多项式项** $J_2$
> $$J = -J_2 = -\iint_D x\,\mathrm{d}x\mathrm{d}y = -\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}}\mathrm{d}y \int_{-1}^{\sin y} x\,\mathrm{d}x$$
> 先对 $x$ 积分：
> $$\int_{-1}^{\sin y} x\,\mathrm{d}x = \frac{1}{2}(\sin^2 y - 1) = -\frac{1}{2}\cos^2 y$$
> 代入外层定积分：
> $$J = -\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} \left(-\frac{1}{2}\cos^2 y\right)\mathrm{d}y = \frac{1}{2}\cdot 2\int_0^{\frac{\pi}{2}} \cos^2 y\,\mathrm{d}y = \frac{\pi}{4}$$
> </small>

### 【必做例题 03】轮换对称性与选择题特值秒杀（PDF 第 3 页例题）

**【题目】** 设 $D = \{(x,y) \mid x^2 + y^2 \le 4, x \ge 0, y \ge 0\}$，$f(u)$ 为正值连续函数，计算积分：
$$I = \iint_D \frac{a\sqrt{f(x)} + b\sqrt{f(y)}}{\sqrt{f(x)} + \sqrt{f(y)}}\,\mathrm{d}\sigma$$

> [!warning] 原笔记核心批注与避坑指南
> * **笔记原话**：“关于 $y = x$ 对称优先考虑轮换对称性，再用 $I = \frac{1}{2}(左端 + 右端)$，最后用极坐标转换或几何意义。”
> * **选择题特化技巧**：若作为客观题出现，由于函数 $f(u)$ 具有任意正值连续性，答案必定与函数具体形态无关，直接令 $f(u) \equiv 1$ 即可秒得结果，节省宝贵的考场时间。

> [!tip]- 参考解答与解析
> <small>
>
> **常规解答题步骤（轮换对称法）：**
> 1. 区域 $D$ 为第一象限内的四分之一圆盘，其几何方程 $x^2 + y^2 \le 4$ 对调 $x, y$ 后完全不变，故区域关于直线 $y = x$ 严格对称。
> 2. 将自变量 $x$ 与 $y$ 全面对调，积分值保持不变：
>    $$I = \iint_D \frac{a\sqrt{f(y)} + b\sqrt{f(x)}}{\sqrt{f(y)} + \sqrt{f(x)}}\,\mathrm{d}\sigma$$
> 3. 两式左右相加：
>    $$2I = \iint_D \frac{(a+b)\big(\sqrt{f(x)} + \sqrt{f(y)}\big)}{\sqrt{f(x)} + \sqrt{f(y)}}\,\mathrm{d}\sigma = (a+b)\iint_D 1\,\mathrm{d}\sigma$$
> 4. 代入第一象限圆面积 $S_D = \frac{1}{4}\pi (2)^2 = \pi$：
>    $$2I = (a+b)\pi \implies I = \frac{a+b}{2}\pi$$
>
> **客观题秒杀步骤（特殊函数法）：**
> 取特殊正值连续函数 $f(u) \equiv 1$，原式立即转化为：
> $$I = \iint_D \frac{a(1) + b(1)}{1 + 1}\,\mathrm{d}\sigma = \frac{a+b}{2}\iint_D 1\,\mathrm{d}\sigma = \frac{a+b}{2}\pi$$
> </small>

## 第二节 累次积分交换次序与反三角设限

### 知识精要（对应 PDF 第 7、8 页）

1. **交换次序的根本动机**：
   * **原函数非初等不可积**：如遇到被积函数含 $e^{-y^2}, \; \frac{\sin y}{y}, \; \sin(x^2), \; e^{x^2}$ 等，对内层变量无法直接求出原函数，必须交换积分次序。
   * **分块累次积分合并化简**：直角坐标下被积区域因凸凹性被分割成多个项，通过交换次序后往往能合为一个单一积分式，简化计算。
2. **极坐标内部交换次序法则（先 $r$ 后 $\theta$ $\iff$ 先 $\theta$ 后 $r$）**：
   * 必须严格将极径边界反解为极角的显式函数 $\theta = \theta(r)$。
   * **极易错点**：反解反三角函数时，必须根据原始极角 $\theta$ 所处的象限，利用诱导公式转换为主值区间，切忌盲目直接套用 $\arcsin$ 或 $\arccos$。

### 【必做例题 04】原函数非初等交换次序（PDF 第 8 页例 (1)）

**【题目】** 计算累次积分：
$$I = \int_0^2 \mathrm{d}x \int_x^2 e^{-y^2}\,\mathrm{d}y$$

> [!warning] 原笔记核心批注与避坑指南
> * **笔记原话**：“不能对 $y$ 直接积分！”
> * **操作准则**：看到 $e^{-y^2}$ 内层为 $\mathrm{d}y$ 时，条件反射判定为不可积型。第一步必须在草稿纸上画出不等式 $0 \le x \le 2, \; x \le y \le 2$ 所确定的三角形区域，改写为横向穿线积分（先对 $x$ 积分），从而产生一次因式 $y$，再通过凑微分 $\mathrm{d}(-y^2)$ 顺利积出。

> [!tip]- 参考解答与解析
> <small>
>
> **步骤 1：由累次积分还原平面区域**
> 原积分表达式的边界为：$0 \le x \le 2, \; x \le y \le 2$。
> 该区域是由下边界直线 $y = x$、左边界 $x = 0$ 以及上边界水平直线 $y = 2$ 所围成的闭三角形区域。
>
> **步骤 2：改变积分次序（先对 $x$ 积分）**
> * 考察纵坐标 $y$ 的全范围：$y \in [0, 2]$。
> * 对固定的 $y$，作平行于 $x$ 轴的水平射线穿入区域，左边界为 $x = 0$，右边界穿出直线为 $x = y$。
> 交换次序得：
> $$I = \int_0^2 \mathrm{d}y \int_0^y e^{-y^2}\,\mathrm{d}x$$
>
> **步骤 3：完成积分计算**
> 先算内层积分：$\int_0^y e^{-y^2}\,\mathrm{d}x = e^{-y^2}\cdot [x]_0^y = y e^{-y^2}$。
> 代入外层定积分并凑微分：
> $$I = \int_0^2 y e^{-y^2}\,\mathrm{d}y = -\frac{1}{2}\int_0^2 e^{-y^2}\,\mathrm{d}(-y^2) = -\frac{1}{2}\Big[e^{-y^2}\Big]_0^2 = \frac{1}{2}(1 - e^{-4})$$
> </small>

### 【必做例题 05】分段累次积分合并化简（PDF 第 8 页例 (2)）

**【题目】** 计算累次积分之和：
$$I = \int_1^2 \mathrm{d}x \int_{\sqrt{x}}^x \sin\frac{\pi x}{2y}\,\mathrm{d}y + \int_2^4 \mathrm{d}x \int_{\sqrt{x}}^2 \sin\frac{\pi x}{2y}\,\mathrm{d}y$$

> [!warning] 原笔记核心批注与避坑指南
> * **笔记原话**：“交换积分次序后可合并为一项！”
> * **破局要领**：题干中两个积分如果单独对 $y$ 积分，均因为含分母变量 $y$ 而陷入繁琐无解；将两块区域在坐标系中拼合，会发现它们恰好组成一个规则的以抛物线和直线为界的单一图形。交换次序后先对 $x$ 积分，正弦函数内层为线性函数，运算极其清爽。

> [!tip]- 参考解答与解析
> <small>
>
> **步骤 1：拼合积分区域**
> 两部分积分区域分别为：
> * $D_1: 1 \le x \le 2, \; \sqrt{x} \le y \le x$
> * $D_2: 2 \le x \le 4, \; \sqrt{x} \le y \le 2$
> 在平面直角坐标系中，下边界整段均为抛物线 $y = \sqrt{x}$（即 $x = y^2$），左上边界为直线 $y = x$，上边界在 $y = 2$ 处平齐封顶。合并后的完整区域为一个关于 $y$ 轴投影规则的单一区域。
>
> **步骤 2：交换次序改写为先对 $x$ 积分**
> * 外层 $y$ 的投影区间为：$y \in [1, 2]$。
> * 对固定的 $y$，水平射线从左侧直线 $x = y$ 穿入，从右侧抛物线 $x = y^2$ 穿出。
> 合并为单项累次积分：
> $$I = \int_1^2 \mathrm{d}y \int_y^{y^2} \sin\frac{\pi x}{2y}\,\mathrm{d}x$$
>
> **步骤 3：内层积分求解**
> $$\int_y^{y^2} \sin\frac{\pi x}{2y}\,\mathrm{d}x = \left[-\frac{2y}{\pi}\cos\frac{\pi x}{2y}\right]_{x=y}^{x=y^2} = -\frac{2y}{\pi}\left(\cos\frac{\pi y}{2} - \cos\frac{\pi}{2}\right) = -\frac{2}{\pi}y\cos\frac{\pi y}{2}$$
>
> **步骤 4：分部积分完成外层**
> $$I = -\frac{2}{\pi}\int_1^2 y\cos\frac{\pi y}{2}\,\mathrm{d}y = -\frac{4}{\pi^2}\int_1^2 y\,\mathrm{d}\left(\sin\frac{\pi y}{2}\right)$$
> 套用分部积分法：
> $$I = -\frac{4}{\pi^2}\left(\left[y\sin\frac{\pi y}{2}\right]_1^2 - \int_1^2 \sin\frac{\pi y}{2}\,\mathrm{d}y\right)$$
> 计算括号内的端点值：
> * $\left[y\sin\frac{\pi y}{2}\right]_1^2 = 2\sin\pi - 1\sin\frac{\pi}{2} = -1$
> * $\int_1^2 \sin\frac{\pi y}{2}\,\mathrm{d}y = \left[-\frac{2}{\pi}\cos\frac{\pi y}{2}\right]_1^2 = -\frac{2}{\pi}(\cos\pi - \cos\frac{\pi}{2}) = \frac{2}{\pi}$
> 整理得：
> $$I = -\frac{4}{\pi^2}\left(-1 - \frac{2}{\pi}\right) = \frac{4}{\pi^2} + \frac{8}{\pi^3}$$
> </small>

### 【必做例题 06】极坐标累次积分反三角定界（PDF 第 7 页例题 · 李林880精选）

**【题目】** 将下列极坐标累次积分交换积分次序：
$$I = \int_{\frac{\pi}{4}}^{\frac{\pi}{2}} \mathrm{d}\theta \int_0^{a\sqrt{\sin 2\theta}} f(r\cos\theta, r\sin\theta)r\,\mathrm{d}r \quad (a > 0)$$

> [!warning] 原笔记核心批注与避坑指南
> * **笔记原话警告**：“$r = a\sqrt{\sin 2\theta} \implies 2\theta = \arcsin\frac{r^2}{a^2}$ 这样解是完全错误的！”
> * **诱导公式避坑**：已知 $\theta \in \left[\frac{\pi}{4}, \frac{\pi}{2}\right]$，则 $2\theta \in \left[\frac{\pi}{2}, \pi\right]$ 落在第二象限！而标准反三角函数 $\arcsin x$ 的值域严格限制在 $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$，因此必须先利用诱导公式转换：$\sin 2\theta = \sin(\pi - 2\theta)$，由于 $\pi - 2\theta \in \left[0, \frac{\pi}{2}\right]$，此时才能两边取反正弦解出 $\theta$。

> [!tip]- 参考解答与解析
> <small>
>
> **步骤 1：确定极径 $r$ 的总变化范围**
> 原积分给定的变化区间为：$\frac{\pi}{4} \le \theta \le \frac{\pi}{2}, \; 0 \le r \le a\sqrt{\sin 2\theta}$。
> 当 $\theta = \frac{\pi}{4}$ 时，$r = a\sqrt{\sin\frac{\pi}{2}} = a$；当 $\theta = \frac{\pi}{2}$ 时，$r = 0$。
> 故极径全范围为：$r \in [0, a]$。
>
> **步骤 2：反求极角下限（诱导公式法）**
> 由边界方程 $r = a\sqrt{\sin 2\theta}$ 得 $\sin 2\theta = \frac{r^2}{a^2}$。
> 判定角区间：$\frac{\pi}{4} \le \theta \le \frac{\pi}{2} \implies \frac{\pi}{2} \le 2\theta \le \pi$。
> 利用正弦诱导公式：$\sin(\pi - 2\theta) = \sin 2\theta = \frac{r^2}{a^2}$。
> 此时角 $\pi - 2\theta \in \left[0, \frac{\pi}{2}\right]$ 处于反正弦主值区间，两边取反正弦：
> $$\pi - 2\theta = \arcsin\frac{r^2}{a^2} \implies \theta = \frac{1}{2}\left(\pi - \arcsin\frac{r^2}{a^2}\right)$$
>
> **步骤 3：写出交换次序后的形式**
> 固定极径 $r \in [0, a]$，极角 $\theta$ 从边界曲线处穿入，在 $\theta = \frac{\pi}{2}$ 处穿出：
> $$I = \int_0^a \mathrm{d}r \int_{\frac{1}{2}\left(\pi - \arcsin\frac{r^2}{a^2}\right)}^{\frac{\pi}{2}} f(r\cos\theta, r\sin\theta)r\,\mathrm{d}\theta$$
> </small>

## 第三节 二重积分综合题：方程、微分与极限

### 知识精要（对应 PDF 第 9、10 页）

1. **二重积分常数性原理（设常数法）**：
   * 在关于变量 $(x,y)$ 的方程中，若出现形式为 $\iint_D f(u,v)\,\mathrm{d}u\mathrm{d}v$ 的项，由于定积分/二重积分计算完毕后只是一个**与自变量无关的确定常数**，应直接设其为常数 $A$。
   * 将代有 $A$ 的函数表达式代回该积分式中建立代数方程，反解出常数 $A$。
2. **变上限二重积分求导（化为一阶线性微分方程）**：
   * 当二重积分区域上限含变参变量 $t$ 时（如 $x^2 + y^2 \le \varphi(t)$），首先转换为极坐标系，将参变量 $t$ 彻底移至最外层积分上限，化为一元变上限积分，两端求导建立微分方程 $y' + P(t)y = Q(t)$ 并求解。
3. **二重积分极限综合解法**：
   * **方法一（洛必达求导）**：化为变上限累次积分，应用含参变量变上限积分求导公式。
   * **方法二（二重积分中值定理）**：$\iint_{D_x} f(t,u)\,\mathrm{d}\sigma = f(\xi,\eta)\cdot S_{D_x}$，通过微元面积消去同阶无穷小分母，直接代入极限点。

### 【必做例题 07】变上限二重积分与微分方程综合（PDF 第 9 页例题）

**【题目】** 设未知函数 $f(t)$ 连续，满足积分方程：
$$f(t) = e^{4\pi t^2} + \iint_{x^2 + y^2 \le 4t^2} f\left(\frac{1}{2}\sqrt{x^2+y^2}\right)\,\mathrm{d}x\mathrm{d}y \quad (t > 0)$$
且已知 $f(0) = 1$，求函数 $f(t)$ 的解析表达式。

> [!warning] 原笔记核心批注与避坑指南
> * **笔记原话**：“二重积分与微分方程结合：化为定积分，两端求导得方程！”
> * **极坐标换元提速**：必须先在二重积分内部采用极坐标，将变量 $t$ 剥离至外层定积分上限：
>   $$\int_0^{2\pi}\mathrm{d}\theta \int_0^{2t} f\left(\frac{r}{2}\right)r\,\mathrm{d}r = 2\pi \int_0^{2t} r f\left(\frac{r}{2}\right)\mathrm{d}r$$
>   然后再做变量代换令 $u = \frac{r}{2}$，将积分上限规整为 $t$，避免在变上限求导时因复合内层而遗漏系数。

> [!tip]- 参考解答与解析
> <small>
>
> **步骤 1：化简二重积分项**
> 积分区域为以原点为中心、半径为 $2t$ 的圆盘。引入极坐标变换：
> $$\iint_{x^2+y^2\le 4t^2} f\left(\frac{1}{2}\sqrt{x^2+y^2}\right)\mathrm{d}x\mathrm{d}y = \int_0^{2\pi}\mathrm{d}\theta \int_0^{2t} f\left(\frac{r}{2}\right)r\,\mathrm{d}r = 2\pi \int_0^{2t} r f\left(\frac{r}{2}\right)\mathrm{d}r$$
> 令换元变量 $u = \frac{r}{2}$，则 $r = 2u, \; \mathrm{d}r = 2\mathrm{d}u$，上限变为 $t$：
> $$2\pi \int_0^t (2u)f(u)\cdot (2\mathrm{d}u) = 8\pi \int_0^t u f(u)\,\mathrm{d}u$$
>
> **步骤 2：建立一阶线性微分方程**
> 原积分方程等价改写为：
> $$f(t) = e^{4\pi t^2} + 8\pi \int_0^t u f(u)\,\mathrm{d}u$$
> 等式两端关于自变量 $t$ 求导：
> $$f'(t) = 8\pi t e^{4\pi t^2} + 8\pi t f(t) \implies f'(t) - 8\pi t f(t) = 8\pi t e^{4\pi t^2}$$
>
> **步骤 3：套用一阶微分方程通解公式**
> 其中 $P(t) = -8\pi t, \; Q(t) = 8\pi t e^{4\pi t^2}$，积分因子为 $e^{-\int 8\pi t\,\mathrm{d}t} = e^{-4\pi t^2}$：
> $$f(t) = e^{4\pi t^2}\left(\int 8\pi t e^{4\pi t^2}\cdot e^{-4\pi t^2}\,\mathrm{d}t + C\right) = e^{4\pi t^2}(4\pi t^2 + C)$$
> 代入初始条件 $f(0) = 1$：
> $$f(0) = e^0(0 + C) = 1 \implies C = 1$$
> 故所求未知函数的解析式为：
> $$f(t) = (4\pi t^2 + 1)e^{4\pi t^2}$$
> </small>

### 【必做例题 08】$0/0$ 型二重积分未定式极限（PDF 第 10 页例题）

**【题目】** 设二元连续函数 $f(t,u)$ 满足 $f(0,0) = -1$，计算极限：
$$L = \lim_{x \to 0^+} \frac{\int_0^{x^2}\mathrm{d}t \int_0^x f(t,u)\,\mathrm{d}u}{1 - e^{-x^3}}$$

> [!warning] 原笔记核心批注与避坑指南
> * **笔记原话**：“法一：洛必达法则；法二：二重积分中值定理。”
> * **秒杀思维推荐**：对于分子为矩形区域的二重积分，区域面积就是两上限之积 $x^2 \cdot x = x^3$。分母等价无穷小同样为 $x^3$。使用中值定理将积分写为 $f(\xi,\eta)\cdot x^3$，因式直接消去，中值点收缩至原点直接得出结果，省去繁重的变上限求导过程。

> [!tip]- 参考解答与解析
> <small>
>
> **步骤 1：分母等价无穷小代换**
> 当 $x \to 0^+$ 时，由泰勒展开可知 $1 - e^{-x^3} \sim x^3$。原式等价转化为：
> $$L = \lim_{x \to 0^+} \frac{\int_0^{x^2}\mathrm{d}t \int_0^x f(t,u)\,\mathrm{d}u}{x^3}$$
>
> **步骤 2：解法一（二重积分中值定理 · 考场首选）**
> 分子累次积分对应的平面区域为矩形 $D_x = [0, x^2] \times [0, x]$，其面积为：
> $$S_{D_x} = x^2 \cdot x = x^3$$
> 根据二重积分中值定理，必存在点 $(\xi_x, \eta_x) \in D_x$（即 $0 \le \xi_x \le x^2, \; 0 \le \eta_x \le x$），使得：
> $$\iint_{D_x} f(t,u)\,\mathrm{d}t\mathrm{d}u = f(\xi_x, \eta_x) \cdot S_{D_x} = f(\xi_x, \eta_x) x^3$$
> 当 $x \to 0^+$ 时，夹逼可知 $\xi_x \to 0, \; \eta_x \to 0$。代入极限表达式：
> $$L = \lim_{x \to 0^+} \frac{f(\xi_x, \eta_x)\cdot x^3}{x^3} = \lim_{x \to 0^+} f(\xi_x, \eta_x) = f(0,0) = -1$$
>
> **步骤 3：解法二（变上限积分求导与洛必达法则 · 严谨推导）**
> 记分子为 $F(x) = \int_0^{x^2} \left(\int_0^x f(t,u)\,\mathrm{d}u\right)\mathrm{d}t$。由变上限复合求导公式：
> $$F'(x) = 2x \int_0^x f(x^2, u)\,\mathrm{d}u + \int_0^{x^2} f(t, x)\,\mathrm{d}t$$
> 再次使用一元积分中值定理：
> * $\int_0^x f(x^2, u)\,\mathrm{d}u = x f(x^2, \xi_1) \implies 2x \cdot x f(x^2, \xi_1) = 2x^2 f(x^2, \xi_1)$
> * $\int_0^{x^2} f(t, x)\,\mathrm{d}t = x^2 f(\xi_2, x)$
> 对 $\frac{F(x)}{x^3}$ 使用洛必达法则：
> $$L = \lim_{x \to 0^+} \frac{2x^2 f(x^2, \xi_1) + x^2 f(\xi_2, x)}{3x^2} = \lim_{x \to 0^+} \frac{2f(x^2, \xi_1) + f(\xi_2, x)}{3} = \frac{2(-1) + (-1)}{3} = -1$$
> </small>
