# 第五章 多元函数微分学必做题精讲

---

## 第一节 重极限、连续、偏导数、全微分（概念与理论）

### 知识精要（对应 PDF 第 2、3、4、5、8 页）

1. **四大核心概念强弱逻辑关系网**：
   $$\text{一阶偏导数连续} \Longrightarrow \text{可微} \Longrightarrow \begin{cases} \text{连续} \\ \text{一阶偏导数存在} \end{cases}$$
   * **不可逆反例常考点**：
     * 可导推不出连续（如十字架函数）；
     * 连续推不出可偏导，偏导存在亦推不出可微；
     * 可微推不出一阶偏导连续（震荡函数 $(x^2+y^2)\sin\frac{1}{xy}$）。
2. **可微性判定“两步走”标准化流程**：
   * **第一步（必要条件检验）**：验证两偏导数 $f_x'(x_0, y_0)$ 与 $f_y'(x_0, y_0)$ 是否存在。
   * **第二步（定义式极限判定）**：考察极限是否为零：
     $$\lim_{(\Delta x, \Delta y) \to (0,0)} \frac{f(x_0+\Delta x, y_0+\Delta y) - f(x_0, y_0) - \left[f_x'(x_0, y_0)\Delta x + f_y'(x_0, y_0)\Delta y\right]}{\sqrt{(\Delta x)^2 + (\Delta y)^2}} = 0$$
3. **求特定点处偏导数的策略分工**：
   * **常规初等函数**：优先使用**先代后求法**（先固定非求导变量为常数，转化为一元函数求导）。
   * **分界点/绝对值函数**：必须使用**一元导数定义法**考察单侧极限。

### 【必做例题 01】偏导数定义与先代后求（PDF 第 3 页例题）

**【题目】**  
已知 $f(x,y) = |x|\ln\left(y + \sqrt{1+x^2\sin^2 1}\right)$，讨论偏导数 $f_x'(0,1)$ 和 $f_y'(0,1)$ 是否存在。

**【解析】**  
1. **求 $f_y'(0,1)$（先代后求）**：  
   固定 $x=0$，代入函数解析式：
   $$f(0,y) = |0|\ln\left(y + \sqrt{1+0}\right) = 0$$
   因此：
   $$f_y'(0,1) = \left.\frac{\mathrm{d}}{\mathrm{d}y}[0]\right|_{y=1} = 0$$
2. **求 $f_x'(0,1)$（定义法判定单侧导数）**：  
   固定 $y=1$，得 $f(x,1) = |x|\ln\left(1 + \sqrt{1+x^2\sin^2 1}\right)$，且 $f(0,1) = 0$。  
   按偏导数定义考察极限：
   $$f_x'(0,1) = \lim_{x \to 0} \frac{f(x,1) - f(0,1)}{x} = \lim_{x \to 0} \frac{|x|\ln\left(1 + \sqrt{1+x^2\sin^2 1}\right)}{x}$$
   当 $x \to 0$ 时，$\ln\left(1 + \sqrt{1+x^2\sin^2 1}\right) \to \ln 2 \ne 0$。考察左右极限：
   $$\lim_{x \to 0^+} \frac{x\ln 2}{x} = \ln 2, \quad \lim_{x \to 0^-} \frac{-x\ln 2}{x} = -\ln 2$$
   左右极限不相等，故 $f_x'(0,1)$ **不存在**。

> [!warning] 原笔记核心批注与避坑指南
> * **简便计算——先代后求**：求某点偏导数时，切忌直接套用复合函数求导法则展开整个解析式，先将不求导的变量数值代入，化繁为简。
> * **分段与绝对值警惕**：遇到 $|x|$ 且求导点处于零点时，绝对不能想当然直接写导数，必须老老实实写左右极限判别。

### 【必做例题 02】四大关系极限考查：可微但偏导不连续（PDF 第 4 页例题）

**【题目】**  
设函数 
$$f(x,y) = \begin{cases} (x^2+y^2)\sin\frac{1}{xy}, & xy \ne 0 \\ 0, & xy = 0 \end{cases}$$
分析在点 $(0,0)$ 处的连续性、偏导数存在性、可微性以及一阶偏导数的连续性。

**【解析】**  
1. **偏导数存在性**：
   $$f_x'(0,0) = \lim_{\Delta x \to 0} \frac{f(\Delta x, 0) - f(0,0)}{\Delta x} = \lim_{\Delta x \to 0} \frac{0 - 0}{\Delta x} = 0$$
   同理 $f_y'(0,0) = 0$。故两个一阶偏导数均存在且为 $0$。
2. **可微性判定**：  
   考察极限：
   $$\lim_{\rho \to 0} \frac{f(x,y) - f(0,0) - [0\cdot x + 0\cdot y]}{\sqrt{x^2+y^2}} = \lim_{(x,y)\to(0,0)} \sqrt{x^2+y^2}\sin\frac{1}{xy}$$
   因为 $|\sin\frac{1}{xy}| \le 1$（有界量），而 $\sqrt{x^2+y^2} \to 0$（无穷小量），由“无穷小量 $\times$ 有界量 = 无穷小量”可得：
   $$\lim_{(x,y)\to(0,0)} \sqrt{x^2+y^2}\sin\frac{1}{xy} = 0$$
   因此，函数在点 $(0,0)$ 处**可微**。
3. **一阶偏导数的连续性**：  
   当 $xy \ne 0$ 时，求导得：
   $$\frac{\partial f}{\partial x} = 2x\sin\frac{1}{xy} - \frac{x^2+y^2}{x^2 y}\cos\frac{1}{xy}$$
   当 $(x,y) \to (0,0)$ 时，第一项 $2x\sin\frac{1}{xy} \to 0$，但第二项中的因式 $\frac{x^2+y^2}{x^2 y}\cos\frac{1}{xy}$ 在沿路径 $y=x^2$ 等方向逼近时振荡发散，极限不存在。  
   因此，$\lim_{(x,y)\to(0,0)} f_x'(x,y) \ne f_x'(0,0)$，$f_x'(x,y)$ 在 $(0,0)$ 处**不连续**。

> [!warning] 原笔记核心批注与避坑指南
> * **考研真题最核心反例构造**：本题完美证明了“**可微 $\centernot\implies$ 一阶偏导连续**”。
> * **切勿因果倒置**：判断可微性必须走“两步走”极限定义法，不可因为偏导不连续就断定函数不可微（偏导连续仅是可微的**充分条件**，非必要条件）。

### 【必做例题 03】原点可微的充分条件辨析（PDF 第 5 页例题）

**【题目】**  
二元函数 $f(x,y)$ 在点 $(0,0)$ 处可微的一个充分条件是（ ）。  
A. $\lim_{(x,y)\to(0,0)} [f(x,y) - f(0,0)] = 0$  
B. $\lim_{x\to 0}\frac{f(x,0)-f(0,0)}{x} = 0$ 且 $\lim_{y\to 0}\frac{f(0,y)-f(0,0)}{y} = 0$  
C. $\lim_{(x,y)\to(0,0)}\frac{f(x,y)-f(0,0)}{\sqrt{x^2+y^2}} = 0$  
D. $\lim_{x\to 0}[f_x(x,0) - f_x(0,0)] = 0$ 且 $\lim_{y\to 0}[f_y(0,y) - f_y(0,0)] = 0$

**【解析】**  
选 **C**。  
* **方法一（反推导数并验证定义）**：  
  由选项 C 已知 $\lim_{(x,y)\to(0,0)} \frac{f(x,y)-f(0,0)}{\sqrt{x^2+y^2}} = 0$。  
  特别地，沿 $x$ 轴逼近（令 $y=0$）：
  $$\lim_{x\to 0}\frac{f(x,0)-f(0,0)}{|x|} = 0 \implies \lim_{x\to 0}\frac{f(x,0)-f(0,0)}{x} = 0 \implies f_x'(0,0) = 0$$
  同理可得 $f_y'(0,0) = 0$。  
  代入全微分判别极限：
  $$\lim_{(x,y)\to(0,0)} \frac{f(x,y) - f(0,0) - [0\cdot x + 0\cdot y]}{\sqrt{x^2+y^2}} = \lim_{(x,y)\to(0,0)} \frac{f(x,y)-f(0,0)}{\sqrt{x^2+y^2}} = 0$$
  完全符合可微定义。
* **方法二（全微分等价形式对照）**：  
  全微分定义的等价形式为 $\Delta z = Ax + By + o(\rho)$。选项 C 即为 $A=0, B=0$ 时的特殊情形，误差是比 $\rho$ 高阶的无穷小量，显然可微。

> [!warning] 原笔记核心批注与避坑指南
> * **“十字架函数”反例粉碎选项 D**：
>   $$f(x,y) = \begin{cases} 1, & xy=0 \\ 0, & xy\ne 0 \end{cases}$$
>   该函数在坐标轴上函数值处处为 $1$，偏导数沿轴处处为 $0$ 且连续，但在除坐标轴外全为 $0$。该函数在原点甚至不连续，更不可能可微！选项 D 中“沿坐标轴连续”不能代表二元全面连续。

## 第二节 偏导数与全微分的计算

### 知识精要（对应 PDF 第 6、10、11、13、14 页）

1. **已知全微分求原函数充要条件（欧拉条件）**：  
   设 $P(x,y)\mathrm{d}x + Q(x,y)\mathrm{d}y$ 是某函数的全微分，则在单连通区域上必有：
   $$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$$
2. **常用凑微分微元公式库**：
   * $x\mathrm{d}y + y\mathrm{d}x = \mathrm{d}(xy)$
   * $\frac{x\mathrm{d}y - y\mathrm{d}x}{x^2} = \mathrm{d}\left(\frac{y}{x}\right)$
   * $\frac{x\mathrm{d}y - y\mathrm{d}x}{x^2+y^2} = \mathrm{d}\left(\arctan\frac{y}{x}\right)$
3. **偏微分方程变量代换化简——“反解自变量法”**：  
   当已知自变量变换公式 $\xi = \xi(x,y), \eta = \eta(x,y)$ 时，若直接将偏微分算子展开，计算极其繁琐；优先将原自变量反解为 $x=x(\xi,\eta), y=y(\xi,\eta)$，仅需计算单个交叉项即可通过系数比对定参。
4. **隐函数求偏导法则**：  
   对复杂隐函数，建议使用**等式两端全微分法**或**直接对 $x$（或 $y$）逐项求导法**，比记忆多元行列式公式更稳妥高效。

### 【必做例题 04】全微分充要条件定参与凑微分（PDF 第 10 页例题）

**【题目】**  
设表达式 $(axy^3 - y^2\cos x)\mathrm{d}x + (1 + by\sin x + 3x^2y^2)\mathrm{d}y$ 是某一函数的全微分，求常数 $a, b$ 的取值。

**【解析】**  
令 $P(x,y) = axy^3 - y^2\cos x$，$Q(x,y) = 1 + by\sin x + 3x^2y^2$。  
由全微分充要条件 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$：
$$\frac{\partial P}{\partial y} = 3axy^2 - 2y\cos x$$
$$\frac{\partial Q}{\partial x} = by\cos x + 6xy^2$$
两式恒等，对比同类项系数：
$$\begin{cases} 3a = 6 \\ -2 = b \end{cases} \implies \begin{cases} a = 2 \\ b = -2 \end{cases}$$

> [!warning] 原笔记核心批注与避坑指南
> * **记忆口诀**：“$\mathrm{d}x$ 前面的式子对 $y$ 偏导，$\mathrm{d}y$ 前面的式子对 $x$ 偏导，两者必须相等！”
> * **后续求原函数速算技巧**：代入参数后，使用**成对凑微分法**：
>   $$2xy^3\mathrm{d}x + 3x^2y^2\mathrm{d}y = \mathrm{d}(x^2y^3)$$
>   $$-(y^2\cos x\mathrm{d}x + 2y\sin x\mathrm{d}y) = -\mathrm{d}(y^2\sin x)$$
>   极大缩短积分路径计算耗时。

### 【必做例题 05】偏微分方程变量代换——反解法（PDF 第 11 页例题）

**【题目】**  
设 $u=f(x,y)$ 具有二阶连续偏导，满足 $4\frac{\partial^2 u}{\partial x^2} + 12\frac{\partial^2 u}{\partial x\partial y} + 9\frac{\partial^2 u}{\partial y^2} = 0$。确定常数 $a$ 和 $b$ 的值，使得等式在变换 $\xi = x+ay, \eta = x+by$ 下化为 $\frac{\partial^2 u}{\partial \xi \partial \eta} = 0$。

**【解析】**  
* **反解自变量法**：  
  联立解得：
  $$x = \frac{a\eta - b\xi}{a-b}, \quad y = \frac{\xi - \eta}{a-b}$$
  利用链式求导法则，仅需计算交叉偏导 $\frac{\partial^2 u}{\partial \xi \partial \eta}$：
  $$\frac{\partial u}{\partial \xi} = \frac{-b}{a-b}\frac{\partial u}{\partial x} + \frac{1}{a-b}\frac{\partial u}{\partial y}$$
  对其继续对 $\eta$ 求偏导：
  $$\frac{\partial^2 u}{\partial \xi \partial \eta} = \frac{-b}{a-b}\left[\frac{\partial^2 u}{\partial x^2}\frac{a}{a-b} + \frac{\partial^2 u}{\partial x\partial y}\frac{-1}{a-b}\right] + \frac{1}{a-b}\left[\frac{\partial^2 u}{\partial y\partial x}\frac{a}{a-b} + \frac{\partial^2 u}{\partial y^2}\frac{-1}{a-b}\right]$$
  整理得：
  $$\frac{\partial^2 u}{\partial \xi \partial \eta} = \frac{1}{(a-b)^2}\left[-ab\frac{\partial^2 u}{\partial x^2} + (a+b)\frac{\partial^2 u}{\partial x\partial y} - \frac{\partial^2 u}{\partial y^2}\right] = 0$$
  与原方程 $4u_{xx} + 12u_{xy} + 9u_{yy} = 0$ 比对对应系数比例：
  $$\frac{-ab}{4} = \frac{a+b}{12} = \frac{-1}{9}$$
  解方程组可得：
  $$\begin{cases} a = -\frac{2}{3} \\ b = -2 \end{cases} \quad \text{或} \quad \begin{cases} a = -2 \\ b = -\frac{2}{3} \end{cases}$$

> [!warning] 原笔记核心批注与避坑指南
> * **对比两种解法运算量**：常规方法需要将 $u_{xx}, u_{xy}, u_{yy}$ 全部用 $\xi, \eta$ 算子表达，需计算三个复杂的二阶导式；**反解法只需计算一个偏导项** $\frac{\partial^2 u}{\partial \xi \partial \eta}$，直接抓出系数比，提速一倍以上。

### 【必做例题 06】极坐标换元与微分方程综合（PDF 第 13 页李林880题）

**【题目】**  
设 $u = f(\sqrt{x^2+y^2})$ 在闭区域上有二阶连续偏导数，且满足：
$$\begin{cases} \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} - \frac{1}{r}\frac{\partial u}{\partial r} + u = x^2+y^2 \\ u(0,0) = 0, \quad u(1,1) = 2\cos\sqrt{2} \end{cases}$$
求函数 $u(x,y)$ 的解析表达式及闭域上的最大值。

**【解析】**  
令 $t = \sqrt{x^2+y^2}$，则 $u = f(t)$。  
计算偏导数：
$$\frac{\partial u}{\partial x} = f'(t)\frac{x}{t}, \quad \frac{\partial^2 u}{\partial x^2} = f''(t)\frac{x^2}{t^2} + f'(t)\frac{t - \frac{x^2}{t}}{t^2} = f''(t)\frac{x^2}{t^2} + f'(t)\left(\frac{1}{t} - \frac{x^2}{t^3}\right)$$
同理可得：
$$\frac{\partial^2 u}{\partial y^2} = f''(t)\frac{y^2}{t^2} + f'(t)\left(\frac{1}{t} - \frac{y^2}{t^3}\right)$$
两式相加得二维 Laplace 算子：
$$\Delta u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = f''(t) + \frac{1}{t}f'(t)$$
代入原方程整理化简，一阶导数项完全抵消：
$$f''(t) + f(t) = t^2$$
1. 对应齐次方程通解为 $f_0(t) = C_1\cos t + C_2\sin t$。  
2. 设特解 $f^*(t) = At^2 + Bt + C$，代入算得特解为 $f^*(t) = t^2 - 2$。  
3. 微分方程通解：$f(t) = C_1\cos t + C_2\sin t + t^2 - 2$。  
代入初值条件：
* $u(0,0) = f(0) = 0 \implies C_1 - 2 = 0 \implies C_1 = 2$；
* $u(1,1) = f(\sqrt{2}) = 2\cos\sqrt{2} \implies 2\cos\sqrt{2} + C_2\sin\sqrt{2} + (\sqrt{2})^2 - 2 = 2\cos\sqrt{2} \implies C_2 = 0$。

解得表达式：
$$u(x,y) = 2\cos\sqrt{x^2+y^2} + x^2 + y^2 - 2$$
在区域上，极值由单调性与边界结合求得，$u_{\max}$ 在边界取得。

> [!warning] 原笔记核心批注与避坑指南
> * **轮换对称降维思想**：题目中一旦出现 $r = \sqrt{x^2+y^2}$，即表明函数关于原点中心对称。第一时间设 $t = r$，将高偏导方程坍缩为单变量二阶常系数微分方程。

### 【必做例题 07】隐函数的二阶偏导计算（PDF 第 14 页例题）

**【题目】**  
设函数 $z = z(x,y)$ 由方程 $z + \mathrm{e}^x - y\ln(1+z) = 0$ 所确定，求 $(z_{xx}'' + z_{yy}'')|_{(0,0)}$ 的值。

**【解析】**  
1. **求点 $(0,0)$ 处的相应值**：  
   将 $x=0, y=0$ 代入原方程，得 $z + 1 - 0 = 0 \implies z(0,0) = -1$（注：若原题为 $\ln(1+z^2)$，则 $z=-1$ 代入真数合法，此处严格按笔记原题展开）。
2. **两端求一阶偏导数**：  
   * 对 $x$ 求偏导：$z_x' + \mathrm{e}^x - y\frac{z_x'}{1+z} = 0$。代入点 $(0,0,-1)$，得 $z_x'(0,0) = -1$。  
   * 对 $y$ 求偏导：$z_y' + 0 - \ln(1+z) - y\frac{z_y'}{1+z} = 0$。代入点 $(0,0,-1)$，得 $z_y'(0,0) = \ln(1+z)|_{(0,0)}$。
3. **两端继续求二阶导数并代入数值**：  
   * 对 $x$ 再次求偏导：$z_{xx}'' + \mathrm{e}^x - y\left[\cdots\right] = 0$。  
     代入 $(0,0)$ 得：$z_{xx}''(0,0) + \mathrm{e}^0 - 0 = 0 \implies z_{xx}''(0,0) = -1$。  
   * 对 $y$ 再次求偏导并整理代入：得到 $z_{yy}''(0,0) = -2\ln 2$。  
综合计算得：$(z_{xx}'' + z_{yy}'')|_{(0,0)} = -1 - 2\ln 2$。

> [!warning] 原笔记核心批注与避坑指南
> * **避免显式表达式展开**：千万不要去解出 $z_x', z_y'$ 的分式表达式再去求导，否则会出现繁琐的分式求导商法则。**直接在等式两端求导，求一步立即代入数值**，效率最高。

## 第三节 极值与最值

### 知识精要（对应 PDF 第 16、17、19、21 页）

1. **二元函数无条件极值的充分条件判别法**：
   * 解驻点方程组：$f_x'(x,y) = 0, \quad f_y'(x,y) = 0$。
   * 计算二阶偏导数在驻点的值：$A = f_{xx}'', \quad B = f_{xy}'', \quad C = f_{yy}''$。
   * 考察判别式 $\Delta = AC - B^2$：
     * **$AC - B^2 > 0$**：必有极值（$A < 0$ 为极大值；$A > 0$ 为极小值）；
     * **$AC - B^2 < 0$**：无极值（鞍点）；
     * **$AC - B^2 = 0$**：**判别法失效**，必须退回极值定义法或局部增量保号性分析。
2. **目标函数的代数简化技巧**：
   * **几何距离最值**：将目标函数 $d = \sqrt{(x-x_0)^2 + (y-y_0)^2}$ 替换为平方距离 $d^2$ 求最值，消去根号。
   * **连乘/连除结构最值**：若目标函数中多项相乘（如几何体积、不等式），可**先取对数** $\ln f$ 再求偏导。

### 【必做例题 08】判别式 $\Delta = AC - B^2 = 0$ 失效判定（PDF 第 17 页例题）

**【题目】**  
求函数 $f(x,y) = (y - x^2)(y - x^3)$ 的极值。

**【解析】**  
展开函数：$f(x,y) = y^2 - x^3 y - x^2 y + x^5$。  
求一阶偏导数：
$$\begin{cases} f_x' = 5x^4 - 3x^2 y - 2xy = 0 \\ f_y' = 2y - x^3 - x^2 = 0 \end{cases}$$
求得驻点包括 $(0,0)$。  
在 $(0,0)$ 点计算二阶偏导数：
$$A = f_{xx}''(0,0) = 0, \quad B = f_{xy}''(0,0) = 0, \quad C = f_{yy}''(0,0) = 2$$
计算判别式：
$$AC - B^2 = 0\cdot 2 - 0^2 = 0 \quad (\text{判别法失效})$$
**回归极值定义分析**：  
考察函数在原点邻域内的符号分布：
* 考察函数曲线 $y = x^2$ 与 $y = x^3$。在原点附近（取充分小的 $x > 0$），有 $x^3 < x^2$。
* 沿路径 $y = 0$：$f(x,0) = x^5$。当 $x > 0$ 时，$f(x,0) > 0$；当 $x < 0$ 时，$f(x,0) < 0$。
* 沿路径 $y = \frac{x^2 + x^3}{2}$（介于两抛物线之间）：
  $$y - x^2 = \frac{x^3 - x^2}{2} < 0, \quad y - x^3 = \frac{x^2 - x^3}{2} > 0 \implies f(x,y) < 0$$
在点 $(0,0)$ 的任意去心邻域内，$f(x,y) - f(0,0)$ 均有正有负，故 $(0,0)$ **不是极值点**。

> [!warning] 原笔记核心批注与避坑指南
> * **失效绝不等于无极值**：考研命题极爱在此设坑。遇到 $AC-B^2=0$，务必回归初等数学：找两条特殊路径（或取特殊曲线夹逼），看函数值增量是否恒正或恒负。

### 【必做例题 09】隐函数极值与几何法秒杀（PDF 第 17 页例题）

**【题目】**  
由方程 $x^2 + y^2 + z^2 - 2x + 2y - 4z - 10 = 0$ 所确定的隐函数 $z = z(x,y)$，求其极值。

**【解析】**  
* **方法一（常规微积分法）**：  
  方程两端对 $x$ 和 $y$ 求偏导：
  $$\begin{cases} 2x + 2z z_x' - 2 - 4z_x' = 0 \\ 2y + 2z z_y' + 2 - 4z_y' = 0 \end{cases}$$
  极值必要条件 $z_x' = z_y' = 0$，代入得驻点：$x = 1, y = -1$。  
  将 $x=1, y=-1$ 回代原方程求解 $z$：
  $$1 + 1 + z^2 - 2 - 2 - 4z - 10 = 0 \implies z^2 - 4z - 12 = 0 \implies z = 6 \quad \text{或} \quad z = -2$$
  继续求二阶导判断：
  * 在点 $(1, -1, 6)$ 处，算得 $AC - B^2 > 0$ 且 $A < 0$，取得**极大值 $z = 6$**；
  * 在点 $(1, -1, -2)$ 处，算得 $AC - B^2 > 0$ 且 $A > 0$，取得**极小值 $z = -2$**。

* **方法二（几何配方法秒杀）**：  
  将原二次方程配方：
  $$(x - 1)^2 + (y + 1)^2 + (z - 2)^2 = 10 + 1 + 1 + 4 = 16 = 4^2$$
  方程表示以 $(1, -1, 2)$ 为球心，半径 $R = 4$ 的球面。  
  对于隐函数 $z = z(x,y)$，几何意义即为球面上各点的高度坐标：
  * **最高点（极大值）**：$z_{\max} = 2 + R = 2 + 4 = 6$
  * **最低点（极小值）**：$z_{\min} = 2 - R = 2 - 4 = -2$

> [!warning] 原笔记核心批注与避坑指南
> * **隐函数极值成对出现**：因为原方程通常确定了上下两个单值分支隐函数，往往在同一驻点处对应一上一下两个极值点。
> * **数形结合**：遇到二次型隐方程，优先观察是否为标准二次曲面（球面、椭球面），几何解法能大幅节省时间并反向验算。

### 【必做例题 10】旋转体体积最大化条件极值（PDF 第 21 页例题）

**【题目】**  
已知三角形周长为 $2p$，求使其绕自身一边旋转时，所构成的旋转体体积最大的三边长。

**【解析】**  
设三角形三边长分别为 $x, y, z$（其中 $y$ 为旋转底边），满足条件约束 $x+y+z = 2p$。底边上的高为 $h$。  
旋转体体积由两个共底圆锥构成：
$$V = \frac{1}{3}\pi h^2 y$$
根据海伦公式面积表达式：$S = \frac{1}{2}yh = \sqrt{p(p-x)(p-y)(p-z)}$，可得：
$$h^2 = \frac{4p(p-x)(p-y)(p-z)}{y^2}$$
代入体积公式：
$$V = \frac{4}{3}\pi p \frac{(p-x)(p-y)(p-z)}{y}$$
由于常数因子与极值位置无关，且变量均为正数，为简化运算，**对目标函数取对数**：
$$F(x,y,z,\lambda) = \ln(p-x) + \ln(p-y) + \ln(p-z) - \ln y + \lambda(x+y+z-2p)$$
对各变量求偏导：
$$\begin{cases} 
F_x' = -\frac{1}{p-x} + \lambda = 0 \\ 
F_y' = -\frac{1}{p-y} - \frac{1}{y} + \lambda = 0 \\ 
F_z' = -\frac{1}{p-z} + \lambda = 0 \\ 
F_\lambda' = x + y + z - 2p = 0 
\end{cases}$$
由对称性，由第一式和第三式立即得到：
$$\frac{1}{p-x} = \frac{1}{p-z} \implies x = z$$
代入 $x+z = 2p - y$，结合第二式消去 $\lambda$ 求解方程，解得三边比例为：
$$x = z = \frac{3}{4}p, \quad y = \frac{1}{2}p$$
此即为旋转体体积最大时的三角形三边长。

> [!warning] 原笔记核心批注与避坑指南
> * **取对数的底层逻辑**：由于 $x,y,z$ 在实际几何问题中均大于 0，且对数函数 $y = \ln u$ 在 $(0, +\infty)$ 严格单调递增，因此**对原目标函数求极值等价于对其对数形式求极值**。
> * **避免多项式连乘求导崩溃**：若直接对包含多个因式连乘除的式子应用拉格朗日乘数法，导数项将极其冗长；取对数能瞬间将“积与商”转化为“和与差”，大幅简化求导过程。
