## 1. 质点运动学

### 1.1 选择题

#### `[2005_A_choice_01]`
一质点沿 $x$ 轴作直线运动，其 $v - t$ 曲线如图所示。若 $t = 0$ 时，质点位于坐标原点，则 $t = 4.5\ \mathrm{s}$ 时，质点在 $x$ 轴上的位置为：
- (A) $5\ \mathrm{m}$
- (B) $2\ \mathrm{m}$
- (C) $0$
- (D) $-2\ \mathrm{m}$
- (E) $-5\ \mathrm{m}$

![[images/a84b2df1195a95bfa8b5eb8135d49de404913731727a45494d02bf5751a24905.jpg]]

> [!tip]- 参考解答与解析
> **答案：B**
> 
> **解析：**
> $v\text{-}t$ 曲线与 $t$ 轴所围的代数面积表示位移，时间轴上方取正，下方取负。
> - $0 \sim 2.5\ \mathrm{s}$ 内面积（正向）：
>   $$s_1 = \frac{1}{2}\times 1\times 2 + 1\times 2 + \frac{1}{2}\times 0.5\times 2 = 3.5\ \mathrm{m}$$
> - $2.5 \sim 4.5\ \mathrm{s}$ 内面积（负向）：
>   $$s_2 = -\left(\frac{1}{2}\times 0.5\times 1 + 1\times 1 + \frac{1}{2}\times 0.5\times 1\right) = -1.5\ \mathrm{m}$$
> 
> 故 $t = 4.5\ \mathrm{s}$ 时质点位置：
> $$x = s_1 + s_2 = 3.5 - 1.5 = 2\ \mathrm{m}$$
> 选项 **B** 正确。

#### `[2005_A2_choice_01]`
一质点在平面上作一般曲线运动，其瞬时速度为 $\mathbf{v}$，瞬时速率为 $v$，某一时间内的平均速度为 $\overline{\mathbf{v}}$，平均速率为 $\bar{v}$，它们之间的关系必定有：
- (A) $|\mathbf{v}| = v,\ |\overline{\mathbf{v}}| = \bar{v}$
- (B) $|\mathbf{v}| \neq v,\ |\overline{\mathbf{v}}| = \bar{v}$
- (C) $|\mathbf{v}| \neq v,\ |\overline{\mathbf{v}}| \neq \bar{v}$
- (D) $|\mathbf{v}| = v,\ |\overline{\mathbf{v}}| \neq \bar{v}$

> [!tip]- 参考解答与解析
> **答案：D**
> 
> **解析：**
> 1. 瞬时速度的模恒等于瞬时速率，即 $|\mathbf{v}| = v$。
> 2. 平均速度的大小为位移的模除以时间 $|\overline{\mathbf{v}}| = \dfrac{|\Delta\mathbf{r}|}{\Delta t}$；平均速率为路程除以时间 $\bar{v} = \dfrac{\Delta s}{\Delta t}$。在一般曲线运动中，位移模小于路程（$|\Delta\mathbf{r}| < \Delta s$），故必有 $|\overline{\mathbf{v}}| \neq \bar{v}$。
> 
> 选项 **D** 正确。

#### `[2007As_B_choice_01]`
某质点作直线运动的运动学方程为 $x = 3t - 5t^3 + 6\ \mathrm{(SI)}$，则该质点作：
- (A) 匀加速直线运动，加速度沿 $x$ 轴正方向
- (B) 匀加速直线运动，加速度沿 $x$ 轴负方向
- (C) 变加速直线运动，加速度沿 $x$ 轴正方向
- (D) 变加速直线运动，加速度沿 $x$ 轴负方向


> [!tip]- 参考解答与解析
> **答案：D**
> 
> **解析：**
> 对运动学方程逐次求导得速度与加速度：
> $$v = \frac{\mathrm{d}x}{\mathrm{d}t} = 3 - 15t^2,\qquad a = \frac{\mathrm{d}v}{\mathrm{d}t} = -30t$$
> 加速度 $a$ 随时间变化，故为变加速运动；当 $t > 0$ 时 $a < 0$，加速度方向始终沿 $x$ 轴负方向。选项 **D** 正确。

#### `[2007Bs_B_choice_02]`
如图所示，假设物体沿着竖直面上圆弧形轨道下滑，轨道是光滑的，在从 $A$ 至 $C$ 的下滑过程中，下面哪个说法是正确的？
- (A) 它的加速度大小不变，方向永远指向圆心
- (B) 它的速率均匀增加
- (C) 它的合外力大小变化，方向永远指向圆心
- (D) 它的合外力大小不变
- (E) 轨道支持力的大小不断增加

![[images/34b9183b93908ec08c804829ba910d40c52dfb00fbc8379495466bcc52e0407e.jpg]]

> [!tip]- 参考解答与解析
> **答案：E**
> 
> **解析：**
> 设下滑到某位置时，圆弧半径与水平方向夹角为 $\theta$。
> 1. 沿法向（指向圆心）：
>    $$N - mg\sin\theta = m\frac{v^2}{R}$$
> 2. 由机械能守恒定律：$v^2 = 2gR\sin\theta$，代入法向方程可得：
>    $$N = 3mg\sin\theta$$
>    随着物体向 $C$ 点下滑，$\theta$ 不断增大，支持力 $N$ 不断增加，选项 **E** 正确。
> 3. 切向加速度 $a_t = g\cos\theta$ 随位置变化，速率并非均匀增加，总加速度与合外力也不单指向圆心。

#### `[2007As_B_choice_04]`
质量为 $m = 0.5\ \mathrm{kg}$ 的质点，在 $Oxy$ 坐标平面内运动，其运动方程为 $x = 5t,\ y = 0.5t^2\ \mathrm{(SI)}$。从 $t = 2\ \mathrm{s}$ 到 $t = 4\ \mathrm{s}$ 这段时间内，外力对质点作的功为：
- (A) $1.5\ \mathrm{J}$
- (B) $3\ \mathrm{J}$
- (C) $4.5\ \mathrm{J}$
- (D) $-1.5\ \mathrm{J}$

> [!tip]- 参考解答与解析
> **答案：B**
> 
> **解析：**
> 速度分量为 $v_x = \dfrac{\mathrm{d}x}{\mathrm{d}t} = 5$， $v_y = \dfrac{\mathrm{d}y}{\mathrm{d}t} = t$，速率平方为 $v^2 = 25 + t^2$。
> 根据动能定理，外力所作总功等于动能增量：
> $$W = \Delta E_k = \frac{1}{2}m\left[v^2(4) - v^2(2)\right] = \frac{1}{2}\times 0.5\times\left[(25 + 16) - (25 + 4)\right] = 3\ \mathrm{J}$$
> 选项 **B** 正确。

#### `[2008Bs_A_choice_01]`
一质点在平面上运动，已知质点位置矢量的表示式为 $\mathbf{r} = at^2\mathbf{i} + bt^2\mathbf{j}$（其中 $a$、$b$ 为非零常量），则质点作：
- (A) 匀速直线运动
- (B) 变速直线运动
- (C) 抛物线运动
- (D) 一般曲线运动


> [!tip]- 参考解答与解析
> **答案：B**
> 
> **解析：**
> 由分量式 $x = at^2$、$y = bt^2$ 消去参量 $t^2$ 可得：
> $$y = \frac{b}{a}x$$
> 轨迹方程为通过原点的直线。速率随时间的关系为：
> $$v = \sqrt{v_x^2 + v_y^2} = \sqrt{(2at)^2 + (2bt)^2} = 2t\sqrt{a^2 + b^2}$$
> 速率随时间线性增大，故该质点作变速直线运动。选项 **B** 正确。

### 1.2 填空题

#### `[2005_A_fill_12]` / `[2005_A2_fill_12]`
两条直路交叉成 $\alpha$ 角，两辆汽车分别以速率 $v_1$ 和 $v_2$ 沿两条路行驶，一车相对另一车的速度大小为 `____`。

> [!tip]- 参考解答与解析
> **答案：** $\sqrt{v_1^2 + v_2^2 - 2v_1v_2\cos\alpha}$ 或 $\sqrt{v_1^2 + v_2^2 + 2v_1v_2\cos\alpha}$
> 
> **解析：**
> 由伽利略相对速度公式 $\mathbf{v}_{12} = \mathbf{v}_1 - \mathbf{v}_2$。
> - 若两车均朝向交叉点（或背离交叉点）同向驶去，速度矢量夹角为 $\alpha$，大小由余弦定理得：
>   $$v_{12} = \sqrt{v_1^2 + v_2^2 - 2v_1v_2\cos\alpha}$$
> - 若其中一车背向行驶，矢量夹角为 $\pi - \alpha$，则根号内符号反转为 $+2v_1v_2\cos\alpha$。

#### `[2007Bs_A_fill_11]` / `[2007Bs_B_fill_11]` / `[2007As_B_fill_14]`
如图所示，沿着半径为 $R$ 的圆周运动的质点，所受的几个力中有一个是恒力 $\mathbf{F}_0$，方向始终沿 $x$ 轴正方向，即 $\mathbf{F}_0 = F_0\mathbf{i}$。当质点从 $A$ 点沿逆时针方向走过 $3/4$ 圆周到达 $B$ 点时，力 $\mathbf{F}_0$ 所作的功为 $W =$ `____`。

![[images/83e3937b15049f44e6cb7b4b21d99f220c117942cb5abfdef4c00679e38ba15c.jpg]]

> [!tip]- 参考解答与解析
> **答案：** $-F_0R$
> 
> **解析：**
> 恒力做功仅取决于始末位置的位移矢量，与路径无关：
> $$W = \mathbf{F}_0 \cdot \Delta\mathbf{r} = F_0(x_B - x_A)$$
> 如图，$A$ 点位于圆周最下方（$x_A = 0$），沿逆时针走过 $3/4$ 周期到达圆周最左端 $B$ 点（$x_B = -R$），故：
> $$W = F_0(-R - 0) = -F_0R$$

#### `[2007As_A_fill_11]`
一质点作直线运动，其坐标 $x$ 与时间 $t$ 的关系曲线如图所示。则该质点在第 `____` 秒瞬时速度为零；在第 `____` 秒至第 `____` 秒间速度与加速度同方向。

> **答案：** $3$；$3$；$6$

> 2. 在 $3 \sim 6\ \mathrm{s}$ 内，曲线单调下凹且越来越陡峭，速度沿负方向（$v < 0$），且速率逐渐增大，加速度亦沿负方向（$a < 0$），两者同向。

#### `[2007As_A_fill_12]`
一船以速度 $\mathbf{v}_0$ 在静水湖中匀速直线航行，一乘客以初速 $\mathbf{v}_1$ 在船中竖直向上抛出一石子，则站在岸上的观察者看石子运动的轨迹是 `____`。取抛出点为原点，$x$ 轴沿 $\mathbf{v}_0$ 方向，$y$ 轴沿竖直向上方向，石子的轨迹方程是 `____`。

![[images/0c08df36f3978c8b771f180a7e247fdbbf26a61197ff35fdb77b257a10ea9487.jpg]]

> [!tip]- 参考解答与解析
> **答案：** 抛物线；$y = \dfrac{v_1}{v_0}x - \dfrac{g}{2v_0^2}x^2$
> 
> **解析：**
> 石子相对岸参与水平向右的匀速运动和竖直方向的竖直上抛运动：
> $$x = v_0 t,\qquad y = v_1 t - \frac{1}{2}gt^2$$
> 从中消去时间参量 $t = \dfrac{x}{v_0}$ 即得轨迹方程：
> $$y = \frac{v_1}{v_0}x - \frac{g}{2v_0^2}x^2$$
> 其几何轨迹为一条开口向下的抛物线。

#### `[2007As_B_fill_11]`
在一个转动的齿轮上，一个齿尖 $P$ 沿半径为 $R$ 的圆周运动，其路程 $S$ 随时间的变化规律为 $S = v_0 t + \frac{1}{2}bt^2$，其中 $v_0$ 和 $b$ 都是正的常量。则 $t$ 时刻齿尖 $P$ 的速度大小为 `____`，加速度大小为 `____`。


> [!tip]- 参考解答与解析
> **答案：** $v_0 + bt$；$\sqrt{b^2 + \dfrac{(v_0 + bt)^4}{R^2}}$
> 
> **解析：**
> 1. 速率即路程对时间的一阶导数：
>    $$v = \frac{\mathrm{d}S}{\mathrm{d}t} = v_0 + bt$$
> 2. 圆周运动切向加速度与法向加速度：
>    $$a_t = \frac{\mathrm{d}v}{\mathrm{d}t} = b,\qquad a_n = \frac{v^2}{R} = \frac{(v_0 + bt)^2}{R}$$
> 3. 总加速度由切向与法向互相垂直合成：
>    $$a = \sqrt{a_t^2 + a_n^2} = \sqrt{b^2 + \frac{(v_0 + bt)^4}{R^2}}$$

#### `[2008As_A_fill_11]` / `[2010As_B_fill_06]`
一物体在某瞬时以初速度 $\mathbf{v}_0$ 从某点开始运动，在 $\Delta t$ 时间内，经一长度为 $S$ 的曲线路径后，又回到原出发点，此时速度为 $-\mathbf{v}_0$，则在这段时间内物体的平均加速度是 `____`。

> [!tip]- 参考解答与解析
> **答案：** $-\dfrac{2\mathbf{v}_0}{\Delta t}$
> 
> **解析：**
> 平均加速度定义为速度变化量与经历时间的比值：
> $$\overline{\mathbf{a}} = \frac{\Delta\mathbf{v}}{\Delta t} = \frac{(-\mathbf{v}_0) - \mathbf{v}_0}{\Delta t} = -\frac{2\mathbf{v}_0}{\Delta t}$$
> 路径长度 $S$ 仅对应平均速率，与矢量平均加速度无关。

#### `[2010As_A_fill_06]`
一物体作匀加速直线运动，通过一段位移 $\Delta x$ 所用的时间为 $t_1$，紧接着通过下一段位移 $\Delta x$ 所用的时间为 $t_2$。则物体运动的加速度为 `____`。

> [!tip]- 参考解答与解析
> **答案：** $\dfrac{2\Delta x(t_1 - t_2)}{t_1 t_2 (t_1 + t_2)}$
> 
> **解析：**
> 匀变速直线运动中，任一段时间内的平均速度等于该时间段中间时刻的瞬时速度：
> $$v_{\text{中}1} = \frac{\Delta x}{t_1},\qquad v_{\text{中}2} = \frac{\Delta x}{t_2}$$
> 两段中间时刻间隔的时间为：
> $$\Delta t = \frac{t_1}{2} + \frac{t_2}{2} = \frac{t_1 + t_2}{2}$$
> 故加速度为：
> $$a = \frac{v_{\text{中}2} - v_{\text{中}1}}{\Delta t} = \frac{\frac{\Delta x}{t_2} - \frac{\Delta x}{t_1}}{\frac{t_1 + t_2}{2}} = \frac{2\Delta x (t_1 - t_2)}{t_1 t_2 (t_1 + t_2)}$$

## 2. 牛顿动力学与动量定理

### 2.1 选择题

#### `[2005_A_choice_02]` / `[2005_A2_choice_02]`
一质量为 $m$ 的滑块，由静止开始沿着 $1/4$ 圆弧形光滑的木槽滑下。设木槽的质量也是 $m$，槽的圆半径为 $R$，放在光滑水平地面上，如图所示。则滑块离开槽时的速度是：
- (A) $\sqrt{2Rg}$
- (B) $2\sqrt{Rg}$
- (C) $\sqrt{Rg}$
- (D) $\frac{1}{2}\sqrt{Rg}$
- (E) $\frac{1}{2}\sqrt{2Rg}$

![[images/9481f9ac293baaa5e6e110344fba85448c543485c3db51662dfac704b2649399.jpg]]

> [!tip]- 参考解答与解析
> **答案：C**
> 
> **解析：**
> 1. 滑块与槽系统在水平方向不受外力作用，系统水平动量守恒。初动量为零，设滑块脱离时速率为 $v$，木槽反向速率为 $V$：
>    $$mv - mV = 0 \implies v = V$$
> 2. 系统各接触面均光滑，机械能守恒：
>    $$mgR = \frac{1}{2}mv^2 + \frac{1}{2}mV^2 = mv^2$$
> 3. 解得滑块速度大小为 $v = \sqrt{Rg}$。选项 **C** 正确。

#### `[2005_A_choice_03]` / `[2005_A2_choice_03]`
在由两个物体组成的系统不受外力作用而发生非弹性碰撞的过程中，系统的：
- (A) 动能和动量都守恒
- (B) 动能和动量都不守恒
- (C) 动能不守恒，动量守恒
- (D) 动能守恒，动量不守恒

> [!tip]- 参考解答与解析
> **答案：C**
> 
> **解析：**
> 系统合外力为零，动量守恒定律必然成立；在非弹性碰撞中，机械能必有耗散（转化为物体内能与形变势能），因此动能不守恒。选项 **C** 正确。

#### `[2006dxwl_A_choice_03]`
一颗速率为 $700\ \mathrm{m/s}$ 的子弹，打穿一块木板后，速率降到 $500\ \mathrm{m/s}$。如果让它继续穿过厚度和阻力均与第一块完全相同的第二块木板，则子弹的速率将降到：（空气阻力忽略不计）
- (A) $300\ \mathrm{m/s}$
- (B) $200\ \mathrm{m/s}$
- (C) $100\ \mathrm{m/s}$
- (D) $50\ \mathrm{m/s}$

> [!tip]- 参考解答与解析
> **答案：C**
> 
> **解析：**
> 两块相同木板的阻力做功相等，设为 $W_f$。
> 对第一块应用动能定理：
> $$W_f = \frac{1}{2}m\left(500^2 - 700^2\right) = \frac{1}{2}m(-240000)$$
> 对第二块应用动能定理：
> $$\frac{1}{2}m v_2^2 - \frac{1}{2}m\cdot 500^2 = W_f = -\frac{1}{2}m(240000)$$
> $$v_2^2 = 250000 - 240000 = 10000 \implies v_2 = 100\ \mathrm{m/s}$$
> 选项 **C** 正确。

#### `[2006dxwl_B_choice_01]`
一公路的水平弯道半径为 $R$，路面的外侧高出内侧，并与水平面夹角为 $\theta$。要使汽车通过该段不引起侧向摩擦力，则汽车的速率为：
- (A) $\sqrt{Rg}$
- (B) $\sqrt{Rg\tan\theta}$
- (C) $\sqrt{\dfrac{Rg\cos\theta}{\sin^{2}\theta}}$
- (D) $\sqrt{Rg\cot\theta}$

![[images/1050e0c20133929c48348215b42cd66e22dc04082c7c94f9823177d8bf55b56f.jpg]]

> [!tip]- 参考解答与解析
> **答案：B**
> 
> **解析：**
> 当无侧向摩擦力时，由支持力 $N$ 与重力 $mg$ 的合力完全提供向心力：
> 竖直方向平衡：$N\cos\theta = mg$
> 水平向心方向：$N\sin\theta = \dfrac{mv^2}{R}$
> 两式相比得 $\tan\theta = \dfrac{v^2}{Rg}$，解得 $v = \sqrt{Rg\tan\theta}$。选项 **B** 正确。

#### `[2006dxwl_B_choice_02]`
质量相等的两个物体甲和乙，并排静止在光滑水平面上。现用一水平恒力 $\mathbf{F}$ 作用在物体甲上，同时给物体乙一个与 $\mathbf{F}$ 同方向的瞬时冲量 $\mathbf{I}$，使两物体沿同一方向运动，则两物体再次达到并排的位置所经过的时间为：
- (A) $I / F$
- (B) $2I / F$
- (C) $2F / I$
- (D) $F / I$

> [!tip]- 参考解答与解析
> **答案：B**
> 
> **解析：**
> 物体乙获得初速度 $v_0 = \dfrac{I}{m}$ 后作匀速运动；物体甲从静止开始以加速度 $a = \dfrac{F}{m}$ 作初速为零的匀加速直线运动。
> 再次并排即位移相等：
> $$\frac{1}{2}a t^2 = v_0 t \implies \frac{1}{2}\left(\frac{F}{m}\right)t^2 = \left(\frac{I}{m}\right)t \implies t = \frac{2I}{F}$$
> 选项 **B** 正确。

#### `[2007Bs_A_choice_01]`

>    $$r_{\min} = \frac{(m - \mu_s M)g}{M \omega^2} = \frac{(0.8 - 0.2\times 2)\times 9.8}{2\times (4\pi)^2} \approx 1.24\times 10^{-2}\ \mathrm{m} = 1.24\ \mathrm{cm}$$

1. 圆盘对地的角速度 $\omega$；
2. 欲使圆盘对地静止，人应沿着 $\frac{1}{2}R$ 圆周对圆盘的速度 $\mathbf{v}$ 的大小及方向？

![[images/dd748b527cc8f9dde958c8794845e74b0cb5185e44cb8e34c0795443c0946deb.jpg]]

> [!tip]- 参考解答与解析
> **解析：**
> 设圆盘质量为 $M$，则人的质量 $m = 0.1M$。人站立在 $r = \frac{R}{2}$ 处。
> 人的转动惯量：
> $$J_{\text{人}} = m r^2 = \frac{1}{10}M\left(\frac{R}{2}\right)^2 = \frac{1}{40}MR^2$$
> 圆盘转动惯量 $J_{\text{盘}} = \frac{1}{2}MR^2 = \frac{20}{40}MR^2$。
> 系统总转动惯量：$J_0 = J_{\text{盘}} + J_{\text{人}} = \frac{21}{40}MR^2$。
> 
> 1. **求盘对地的角速度：**
>    当人相对盘以反向速率 $v$ 行走时，人相对盘的角速度大小为 $\omega_{\text{相}} = \dfrac{v}{R/2} = \dfrac{2v}{R}$。
>    设此时盘对地的角速度为 $\omega$，则人对地的角速度为：
>    $$\omega_{\text{人}} = \omega - \frac{2v}{R}$$
>    转轴光滑，系统对竖直轴的合外力矩为零，角动量守恒：
>    $$J_0 \omega_0 = J_{\text{盘}}\omega + J_{\text{人}}\omega_{\text{人}}$$
>    $$\frac{21}{40}MR^2 \omega_0 = \frac{20}{40}MR^2 \omega + \frac{1}{40}MR^2 \left(\omega - \frac{2v}{R}\right)$$
>    $$21\omega_0 = 21\omega - \frac{2v}{R} \implies \omega = \omega_0 + \frac{2v}{21R}$$
> 
> 2. **使圆盘对地静止时的相对速率：**
>    令 $\omega = 0$：
>    $$\omega_0 + \frac{2v}{21R} = 0 \implies v = -\frac{21}{2}R\omega_0 = -10.5 R\omega_0$$
>    负号说明：人相对圆盘行走的实际方向应与圆盘初始转动方向相同，速率大小为 $\dfrac{21}{2}R\omega_0$。

>    $$T r = J \beta = J \frac{a}{r}$$
> 4. 联立消去张力 $T$：
>    $$J = \frac{T r^2}{a} = \frac{m(g - a)r^2}{a} = mr^2\left(\frac{g}{a} - 1\right)$$
> 5. 将 $a = \dfrac{2S}{t^2}$ 代入可得：
>    $$J = mr^2\left(\frac{gt^2}{2S} - 1\right)$$

#### `[2010As_A_calc_11]`
质量 $M = 2\ \mathrm{kg}$ 的滑块套在光滑的水平轨道上，质量 $m = 1\ \mathrm{kg}$ 的小球通过长 $L = 0.5\ \mathrm{m}$ 的轻质细杆与滑块上的光滑轴 $O$ 连接，小球和轻杆可在竖直平面内绕 $O$ 轴自由转动。开始轻杆处于水平状态。现给小球一个竖直向上的初速度 $v_0 = 4\ \mathrm{m/s}$（取 $g = 10\ \mathrm{m/s^2}$）。
1. 若锁定滑块，试求小球通过最高点 $P$ 时对轻杆的作用力大小和方向；
2. 若解除对滑块的锁定，试求小球通过最高点时的速度大小。


> [!tip]- 参考解答与解析
> **解析：**
> 1. **锁定滑块时：**
>    小球绕固定轴 $O$ 摆动，上升过程机械能守恒。初位置杆水平，取其为势能零点，最高点高度上升 $L$：
>    $$\frac{1}{2}m v_0^2 = \frac{1}{2}m v_1^2 + mgL$$
>    $$v_1^2 = v_0^2 - 2gL = 4^2 - 2\times 10\times 0.5 = 6\ \mathrm{m^2/s^2}$$
>    设在最高点轻杆对球的拉力方向竖直向下，大小为 $F$：
>    $$F + mg = m\frac{v_1^2}{L} \implies F = m\left(\frac{v_1^2}{L} - g\right) = 1\times\left(\frac{6}{0.5} - 10\right) = 2\ \mathrm{N}$$
>    计算结果 $F > 0$，说明杆对小球的作用力方向确为竖直向下（拉力）。
>    由牛顿第三定律，小球对轻杆的作用力大小为 $2\ \mathrm{N}$，方向**竖直向上**。
> 
> 2. **解除滑块锁定后：**
>    系统在水平方向不受外力，水平动量守恒。最高点时，小球只有水平速度 $v_2$，滑块速度为 $V$：
>    $$m v_2 + M V = 0 \implies V = -\frac{m}{M}v_2 = -\frac{1}{2}v_2$$
>    全系统机械能守恒：
>    $$\frac{1}{2}m v_0^2 = \frac{1}{2}m v_2^2 + \frac{1}{2}M V^2 + mgL$$
>    代入数据：
>    $$\frac{1}{2}\times 1\times 4^2 = \frac{1}{2}\times 1\times v_2^2 + \frac{1}{2}\times 2\times\left(-\frac{1}{2}v_2\right)^2 + 1\times 10\times 0.5$$
>    $$8 = \frac{1}{2}v_2^2 + \frac{1}{4}v_2^2 + 5 \implies \frac{3}{4}v_2^2 = 3 \implies v_2 = 2\ \mathrm{m/s}$$
>    即小球通过最高点时的速度大小为 $2\ \mathrm{m/s}$。

#### `[2010As_A_calc_12]`
如图所示，转轮 $A$、$B$ 可分别独立地绕光滑的固定轴 $O$ 转动，它们的质量分别为 $m_A = 10\ \mathrm{kg}$ 和 $m_B = 20\ \mathrm{kg}$，半径分别为 $r_A$ 和 $r_B$。现用力 $f_A$ 和 $f_B$ 分别向下拉绕在轮上的细绳且使绳与轮之间无滑动。为使 $A$、$B$ 轮边缘处的切向加速度相同，相应的拉力 $f_A$、$f_B$ 之比应为多少？（其中 $A$、$B$ 轮绕 $O$ 轴转动时的转动惯量分别为 $J_A = \frac{1}{2}m_A r_A^2$ 和 $J_B = \frac{1}{2}m_B r_B^2$）

![[images/09f6ceee268fa6cfd003472c2cc738bfe32ffe2ddcd1c10b72b29fdb18ee992a.jpg]]

> [!tip]- 参考解答与解析
> **解析：**
> 1. 根据刚体定轴转动定律 $M = J\beta$，对两轮分别有：
>    $$f_A r_A = J_A \beta_A = \left(\frac{1}{2}m_A r_A^2\right)\beta_A \implies \beta_A = \frac{2f_A}{m_A r_A}$$
>    $$f_B r_B = J_B \beta_B = \left(\frac{1}{2}m_B r_B^2\right)\beta_B \implies \beta_B = \frac{2f_B}{m_B r_B}$$
> 2. 轮边缘的切向加速度为 $a_t = r\beta$：
>    $$a_{tA} = r_A \beta_A = \frac{2f_A}{m_A}$$
>    $$a_{tB} = r_B \beta_B = \frac{2f_B}{m_B}$$
> 3. 要求切向加速度相同（$a_{tA} = a_{tB}$）：
>    $$\frac{2f_A}{m_A} = \frac{2f_B}{m_B} \implies \frac{f_A}{f_B} = \frac{m_A}{m_B} = \frac{10}{20} = \frac{1}{2}$$
>    即相应的拉力之比为 $1 : 2$。
